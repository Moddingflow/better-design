Webhooks that land.

Send one API call. Relayhook signs the payload, delivers it to every subscribed endpoint, and retries each one until it answers 2xx.

Retries on a schedule.

When an endpoint errors or times out, Relayhook tries again with exponential backoff and stops at the first 2xx. Set the schedule and the give-up point per endpoint.

Signed with your secret.

Every request carries an HMAC-SHA256 signature and a timestamp. Check both and reject anything stale or forged.

// Node.js, inside your webhook handler
const sig = req.headers["relayhook-signature"];
const ts  = req.headers["relayhook-timestamp"];
const ok  = relayhook.verify(rawBody, sig, ts, SECRET);
if (!ok) return res.status(400).end();

Every attempt, on record.

Inspect the headers, body, and response of each attempt, then replay any event to its endpoint.

Send your first event.

Register an endpoint once, then post events. Relayhook handles fan-out, signing, and retries.

curl https://api.relayhook.test/v1/events \
  -H "Authorization: Bearer $RELAYHOOK_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type": "invoice.paid", "data": {"invoice": "in_1042", "amount": 4900}}'
import { Relayhook } from "relayhook";

const relayhook = new Relayhook(process.env.RELAYHOOK_KEY);

await relayhook.events.send({
  type: "invoice.paid",
  data: { invoice: "in_1042", amount: 4900 },
});
import os
from relayhook import Relayhook

relayhook = Relayhook(os.environ["RELAYHOOK_KEY"])

relayhook.events.send(
    type="invoice.paid",
    data={"invoice": "in_1042", "amount": 4900},
)
