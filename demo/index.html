driftline · built with Better Design Open full page ›

Prompt for both: Make me a website for Driftline, a night-train booking service: overnight sleeper routes between European cities. People pick a route and date, compare seat, couchette and private cabin, and book. The second run added “Use the better-design skill.” Built with v1.7.

v1.6 or v1.8, six briefs with no style given

Each page was built by a fresh agent from a one-line request and nothing else. v1.6 fell back to one house style; v1.8 deals a direction. Every page is live: open the forms, tabs and menus.

Two blind judges, who saw unlabeled screenshots in random order, each grouped five of the six v1.6 pages into one cluster: the same dark template with different words. One generation per brief and version, so treat it as a signal, not a statistic. Method, both iterations, and the misses are in the bench report.
